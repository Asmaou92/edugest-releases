# EduGest Sénégal — installateurs

Ce dépôt contient uniquement les **installateurs Windows** d'EduGest Sénégal, logiciel de gestion scolaire
(élèves, notes et bulletins, paiements, présences, cartes scolaires…).

- **Installer EduGest** : ouvrez la dernière version dans [Releases](../../releases/latest) et téléchargez le fichier `…_x64-setup.exe`.
- **Mises à jour** : une fois installé, EduGest propose lui-même les nouvelles versions au démarrage.
  Chaque version est signée : l'application refuse toute version qui n'a pas été publiée par l'éditeur.
